# Conceptual-model_PetShop_GaleraTech
🐾 Modelagem de banco de dados (MER) do Pet Shop Galera Tech, um sistema multiloja. Cobre tutores, pets, lojas, funcionários, serviços e atendimentos, com itens de atendimento ligando cada serviço realizado. Inclui chaves, atributos e cardinalidades (1,n) e (1,1), servindo de base para os modelos lógico e físico em SQL.
